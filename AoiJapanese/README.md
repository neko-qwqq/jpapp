# Aoi Japanese

一款 SwiftUI iPhone 日语学习 App 原型，面向零基础到 JLPT N3 的碎片化学习。

## 技术栈

- iOS 18+
- SwiftUI
- Observation
- MVVM
- Mock Data
- Xcode project

## 运行方式

1. 使用 Xcode 打开 `AoiJapanese.xcodeproj`
2. 选择 iPhone 模拟器
3. 运行 `AoiJapanese` Target

## 当前功能

- 首页：今日学习进度、JLPT 等级、连续打卡、今日单词、今日语法、学习时间统计、AI 学习助手入口
- 单词：等级筛选、搜索、收藏、单词卡片翻转
- 课程：零基础、N5、N4、N3 学习路径和课程详情
- AI 对话：Mock AI 回复、场景切换、输入与自然滚动
- 我的：学习统计、成就徽章、设置入口
